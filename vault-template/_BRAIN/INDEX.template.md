# INDEX — карта хранилища

> Источник истины по структуре. Где что лежит. Меняешь структуру — правишь здесь.

## Ядро (горячее, всегда в контексте)

| Файл | Назначение |
|---|---|
| `CONTEXT.md` | Кто я, фокус, приоритеты (≤100 строк) |
| `STATE.md` | Рабочее состояние: фокус сейчас + активные проекты |
| `STACK.md` | Инфраструктура: домены, сервера, репо, указатели на ключи |
| `PROJECTS.md` | Канбан проектов: цель / шаг / блокеры / статус |
| `MEMORY.md` | Индекс доменной памяти (по одной строке на домен) |
| `hot.md` | Кэш «где остановился» (АВТО, руками не правим) |
| `CRITICAL_FACTS.md` | ~120 токенов всегда-в-контексте: таймзона, роль, ключевое |

## Папки

| Папка | Назначение |
|---|---|
| `Заметки/` | Факты, методы, цифры. Атомарные заметки с тегами |
| `Решения/` | ADR — решения с аргументацией |
| `Выводы/` | Логи и итоги сессий по датам |
| `Стратегии/` | Долгоиграющие планы и стратегии |
| `Встречи/` | Расшифровки и заметки со встреч |
| `Postmortem/` | Разборы провалов и закрытых проектов |
| `Архив/` | Неактуальное, но удалять жалко |
| `raw/` | Immutable-источники: сырьё, не редактируем |
| `Роли/` | Промпты-роли и режимы работы ассистента |

## Правило

Не нашёл в ядре — ищи грепом по `Заметки/` и `Стратегии/`, не переисследуй.
