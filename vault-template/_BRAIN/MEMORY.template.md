# MEMORY — индекс доменной памяти

> По одной строке на домен знаний: где искать детали.
> Правило: дополняй существующую запись, не плоди дубли. Новый факт — в `Заметки/`, сюда — только ссылку.

## Домены

- {{ДОМЕН_ЗНАНИЙ}} → детали в `Заметки/{{ТЕМА}}/`, ключевое: {{ОДНА_СТРОКА}}
- {{ДОМЕН_ЗНАНИЙ}} → детали в `Стратегии/{{ФАЙЛ}}`, ключевое: {{ОДНА_СТРОКА}}
- {{ДОМЕН_ЗНАНИЙ}} → решения в `Решения/`, ключевое: {{ОДНА_СТРОКА}}
