# Видео-пайплайн — фото → голос → говорящая голова → монтаж

Собирает видео с цифровым аватаром из одного фото и текста: картинка → озвучка → липсинк → монтаж. Триггерится на «оживи фото», «сделай говорящую голову», «озвучь текст голосом», «собери ролик из аватара».

> ⚠️ **Нужна подписка Higgsfield.** Генерация картинок и видео идёт через Higgsfield MCP — без активной подписки шаги генерации не запустятся. Ключ кладём **только в `.env`**, в `.md` — никогда (см. Key-flow ниже).

## Что это (обобщённо)
Конвейер из четырёх стадий. Каждая стадия — отдельный шаг, можно гонять по отдельности и переснимать только сломавшийся кусок, не пересобирая всё.

1. **Картинка — аватар из фото (image-to-image).**
   Из исходного фото лица генерируется чистый кадр-аватар нужного ракурса/фона/света под сцену. Сюда же — генерация фонов и врезок. Делается через Higgsfield MCP (image-модель). Цель — получить опорный кадр, с которого будет «говорить» аватар.

2. **Озвучка (TTS).**
   Текст реплики → аудиодорожка через TTS-провайдера. Голос (клон или сток) и язык — параметры стадии, задаются в конфиге проекта, **не зашиты** в скилл. Результат — `.wav/.mp3` дорожка под каждую реплику.

3. **Говорящая голова (audio-driven / липсинк).**
   Опорный кадр-аватар + аудиодорожка → видео, где губы и мимика синхронны с речью (audio-driven модель через Higgsfield MCP). На выходе — клип говорящей головы под каждую реплику.

4. **Монтаж.**
   Склейка клипов, врезок и фонов, субтитры, музыка/громкость, тайминг и экспорт под площадку (вертикаль/горизонталь). Локальный шаг (ffmpeg-класс), ключей не требует.

**Зачем разбито на стадии:** дорогое (генерация через подписку) отделено от дешёвого (монтаж). Переозвучил реплику — пересобрал только её клип, картинку и монтаж не трогаешь. Экономит и время, и кредиты подписки.

## Что для чего (быстрая карта)
| Стадия | Вход | Выход | Где считается | Нужен ключ |
|---|---|---|---|---|
| 1. Аватар (i2i) | фото лица + промпт сцены | опорный кадр | Higgsfield MCP | да (подписка) |
| 2. Озвучка (TTS) | текст реплики | аудиодорожка | TTS-провайдер | да (TTS-ключ) |
| 3. Говорящая голова | кадр + аудио | клип-липсинк | Higgsfield MCP | да (подписка) |
| 4. Монтаж | клипы + врезки | финальный ролик | локально | нет |

> Конкретные модели, `voice_id` и провайдеры тут **не фиксируем** — они задаются в `.env`/конфиге твоего проекта. Скилл описывает метод, не привязку.

## Key-flow (как ставится ключ)
При установке модуля:
1. Создаётся рабочая папка проекта `Projects/video/` и в ней `.env` с **плейсхолдером** ключа (без значения).
2. Тебе говорится:
   > «Пока я доставляю модуль — **иди сделай ключ Higgsfield** (нужна подписка). Папку `Projects/video/` и `.env` я создал. Как будет ключ — вставишь его в `.env` (не в `.md`!) и запускаешься оттуда.»
3. Ключ просим **в конце**, не блокируя установку. Значение ключа в `.md`/в горячее ядро не пишем — только в `.env` проекта.

`.env` (плейсхолдеры, реальные значения — руками после получения ключа):
```
# Higgsfield — нужна активная подписка. Вставь свой ключ ниже, в .md не дублируй.
HIGGSFIELD_API_KEY=
# TTS-провайдер (выбери своего): ключ и голос
TTS_API_KEY=
TTS_VOICE_ID=
```
В `STACK.md` пишем только **указатель**: «ключ Higgsfield — в `Projects/video/.env` (переменная `HIGGSFIELD_API_KEY`)», без значения.

## Запуск (метод)
1. Открой проект из `Projects/video/` — оттуда читается `.env`.
2. Дай сцену: фото-исходник + текст реплик (+ опц. фон/ракурс).
3. Скилл прогоняет стадии 1→4, показывая промежуточный результат каждой стадии и спрашивая «ок / переснять?» перед дорогими шагами.
4. Финальный ролик кладётся в `Projects/video/out/`.

## Границы (что НЕ делает)
- Не пишет сам сценарий с таймингом хука/CTA → это `scenario`.
- Не публикует ролик на площадки (автопостинг — отдельный модуль/процесс).
- Без активной подписки Higgsfield стадии 1 и 3 не запускаются — предупреждает и останавливается, а не делает «как-нибудь».
- Секреты в `.md` не пишет — только в `.env`, в `STACK.md` указатель.
