## Пути развития

### Для начинающих

1. `skill_technical_seo_audit` → базовая техническая диагностика
2. `skill_on_page_optimization` → оптимизация страниц
3. `skill_keyword_research` → исследование ключевых слов

### Для продвинутых

1. `skill_seo_strategy` → стратегическое планирование
2. `skill_entity_seo` → работа с сущностями
3. `skill_link_building` → построение авторитетности

### Специализация

- **Local:** `skill_local_seo`
- **E-commerce:** `skill_ecommerce_seo`
- **Enterprise:** `skill_entity_seo` + `skill_seo_strategy`

- **Начинай с `skill_technical_seo_audit`** — техническая база первична
