# Стратегия Link Building

**Контекст:** Применяется для разработки и реализации стратегии построения ссылок. Результат — план link building с тактиками, целями outreach и метриками успеха.

**Роль:** При использовании этого навыка обязательно ориентируйся на философию и принципы работы роли [@roles/seo_manager/_role_seo_manager.md](../_role_seo_manager.md). Навык определяет КАК выполнять задачу, а роль определяет КАК ДУМАТЬ при её выполнении. Для работы с терминами используй материалы из [`knowledge/`](../knowledge/).

---

## 1. Назначение

### 1.1 Задача навыка

Разработать стратегию link building, которая:
- Определяет типы linkable assets для создания
- Выявляет возможности для получения editorial links
- Формирует план outreach с целевыми сайтами
- Включает аудит текущего ссылочного профиля
- Использует только white hat подходы

### 1.2 Data Contract

| | Описание |
|---|----------|
| **Input** | URL сайта, ниша/индустрия, конкуренты, текущий контент, бюджет/ресурсы на outreach |
| **Output** | Link building стратегия, список linkable assets, prospect list для outreach, план действий, метрики успеха |

## 2. Методология

### 2.1 Теоретическая база

**Link Earning Framework** — ссылки зарабатываются через создание ценности, которой хотят делиться. Editorial links от релевантных источников — единственный устойчивый подход. Link schemes рано или поздно обнаруживаются.

### 2.2 Ключевые принципы

- **Ссылки = голоса доверия:** Качество источника важнее количества ссылок.
- **Content first:** Без linkable content нечего продвигать. Сначала создай ценность.
- **Relationships > transactions:** Link building — это networking, не покупка.
- **Relevance > authority:** Ссылка от релевантного нишевого сайта ценнее, чем от нерелевантного крупного.

## 3. Алгоритм выполнения

### 3.1 Шаг 1. Аудит текущего ссылочного профиля

**Цель:** Понять текущее состояние и benchmark.

**Действия:**
1. Анализ через Ahrefs/Semrush:
   - Количество referring domains
   - Domain Rating / Domain Authority
   - Anchor text distribution
   - Link velocity (скорость получения)
2. Оценка качества:
   - Топ-20 ссылающихся доменов — релевантны?
   - Есть ли toxic links? (спам, PBN, нерелевантные)
   - Anchor text естественный? (branded > exact match)
3. Сравнение с конкурентами:
   - Количество referring domains
   - Откуда у них ссылки, а у нас нет?
   - Link gap analysis

**Результат:** Baseline метрик и list of opportunities.

---

### 3.2 Шаг 2. Анализ конкурентов

**Цель:** Найти link opportunities от конкурентов.

**Действия:**
1. Определи топ-3-5 конкурентов по органике
2. Проанализируй их backlink profiles:
   - Откуда получают ссылки?
   - Какие типы контента привлекают ссылки?
   - Какие сайты ссылаются на нескольких конкурентов?
3. Выяви patterns:
   - Guest posts на каких площадках?
   - Resource pages в нише
   - Упоминания в медиа
   - Industry directories
4. Составь список:
   - Сайты, которые ссылаются на 2+ конкурентов (высокая вероятность получить)
   - Уникальные источники топ-конкурента

**Результат:** Competitor link analysis и prospect list.

---

### 3.3 Шаг 3. Определение Linkable Assets

**Цель:** Определить или создать контент, достойный ссылок.

**Действия:**
1. Типы linkable assets:
   | Тип | Описание | Пример |
   |-----|----------|--------|
   | **Original Research** | Уникальные данные, surveys | Industry benchmarks report |
   | **Tools & Calculators** | Бесплатные полезные инструменты | ROI calculator |
   | **Comprehensive Guides** | Ultimate guides по теме | "Complete Guide to X" |
   | **Infographics** | Visual data presentation | Statistics infographic |
   | **Case Studies** | Реальные результаты с данными | Before/after analysis |
   | **Expert Roundups** | Мнения экспертов индустрии | "20 Experts on Future of X" |

2. Оцени существующий контент:
   - Что уже привлекает ссылки?
   - Что можно улучшить до "linkable"?
3. Определи gaps:
   - Какой тип контента отсутствует?
   - Что конкуренты делают, а мы нет?
4. Приоритизируй создание:
   - Effort vs potential links
   - Relevance to business
   - Uniqueness in niche

**Результат:** Список linkable assets (существующих и для создания).

---

### 3.4 Шаг 4. Формирование Prospect List

**Цель:** Создать список целевых сайтов для outreach.

**Действия:**
1. Категории prospects:
   - **Resource pages:** "Best resources for X", "Useful links"
   - **Bloggers в нише:** Пишут на релевантные темы
   - **Industry publications:** Trade magazines, online journals
   - **News sites:** Local/national media
   - **Educational sites:** .edu с релевантными программами
   - **Competitor linkers:** Сайты, ссылающиеся на конкурентов
2. Поиск prospects:
   - `"keyword" + "resources"`, `"keyword" + "links"`
   - `"keyword" + "best of"`, `"keyword" + "guide"`
   - `site:.edu "keyword"`
   - Competitor backlink analysis
3. Квалификация:
   - Relevance (тематическое соответствие)
   - Authority (DR/DA, traffic)
   - Activity (публикуют ли свежий контент?)
   - Contact available (есть ли способ связаться?)
4. Создай spreadsheet:
   | Site | DR | Traffic | Relevance | Contact | Status |
   |------|----|---------:|-----------|---------|--------|

**Результат:** Qualified prospect list (50-200+ сайтов).

---

### 3.5 Шаг 5. Стратегии получения ссылок

**Цель:** Определить тактики под каждый тип opportunity.

**Действия:**
1. **Broken Link Building:**
   - Найди resource pages в нише
   - Проверь на broken links (404)
   - Создай контент-замену
   - Outreach: "Нашёл broken link, вот рабочая альтернатива"

2. **Skyscraper Technique:**
   - Найди популярный контент с много ссылок
   - Создай лучшую версию (глубже, свежее, лучше дизайн)
   - Outreach к тем, кто ссылался на оригинал

3. **Guest Posting:**
   - Найди сайты, принимающие guest posts
   - Предложи уникальную тему, ценную для их аудитории
   - ⚠️ Качество > количество. Массовый guest posting = спам

4. **Digital PR:**
   - Создай newsworthy content (research, data)
   - Outreach к журналистам
   - HARO (Help A Reporter Out)
   - Стань экспертным источником

5. **Unlinked Mentions:**
   - Найди упоминания бренда без ссылки (Ahrefs Alerts)
   - Outreach с просьбой добавить ссылку

6. **Resource Link Building:**
   - Создай ultimate resource по теме
   - Найди resource pages
   - Outreach с предложением добавить

**Результат:** Тактики с описанием процесса.

---

### 3.6 Шаг 6. Outreach Process

**Цель:** Организовать эффективный outreach.

**Действия:**
1. Принципы outreach:
   - **Персонализация:** Покажи, что знаешь сайт/человека
   - **Ценность:** Объясни, почему ссылка полезна им
   - **Краткость:** Быстро к сути (3-5 предложений)
   - **Follow-up:** 1-2 follow-up допустимы

2. Шаблон письма:
   ```
   Subject: [Specific, relevant subject line]

   Hi [Name],

   I was reading your article on [Topic] and noticed [specific detail].

   I recently published [Your Content] that [adds value / complements].

   Would you consider adding a link from [their page] to [your page]?

   [One sentence about why it benefits their readers]

   Thanks,
   [Your Name]
   ```

3. Чего избегать:
   - ❌ Mass generic emails
   - ❌ Предложения обмена ссылками
   - ❌ Предложения оплаты
   - ❌ Манипулятивные tactics

4. Preciprocation (давай ценность ДО запроса):
   - Share их контент в соцсетях
   - Комментируй их статьи
   - Упомяни их в своём контенте

**Результат:** Outreach process и templates.

---

### 3.7 Шаг 7. Метрики и tracking

**Цель:** Определить KPIs и систему отслеживания.

**Действия:**
1. KPIs для link building:
   - Количество новых referring domains (в месяц)
   - Domain Rating growth
   - Link velocity
   - Outreach response rate
   - Conversion rate (ответ → ссылка)

2. Tracking system:
   - Spreadsheet для prospects
   - Статусы: Identified → Contacted → Responded → Won/Lost
   - Даты contact и follow-up
   - Notes по каждому prospect

3. Reporting:
   - Ежемесячный отчёт по новым ссылкам
   - Качество полученных ссылок
   - ROI link building activities

**Результат:** KPIs и tracking система.

---

**Цель:** Убедиться, что стратегия полная и реализуемая.

**Чек-лист:**
- [ ] Текущий ссылочный профиль проанализирован (DR, referring domains, anchors)
- [ ] Конкуренты проанализированы (откуда ссылки, gaps)
- [ ] Linkable assets определены (существующие и для создания)
- [ ] Prospect list создан и квалифицирован (50+ сайтов)
- [ ] Тактики определены под каждый тип opportunity
- [ ] Outreach templates подготовлены
- [ ] KPIs определены
- [ ] Только white hat подходы (нет покупки ссылок, PBN, schemes)

**Результат:** Link building стратегия готова к реализации.

## 9. Примеры

### 9.1 Правильное выполнение

**Linkable Asset:** "2025 State of Remote Work Report" — оригинальное исследование с уникальными данными.

**Outreach:**
```
Hi Sarah,

I noticed your comprehensive guide to remote team management — 
really helpful breakdown of async communication tools.

We just published our 2025 State of Remote Work Report with data 
from 5,000+ remote workers on productivity trends and challenges.

Given your focus on remote work best practices, I thought your 
readers might find our salary and benefit benchmarks useful. 
Would you consider adding it as a resource?

Best,
[Name]
```

**Почему правильно:** Персонализация (конкретная статья), ценность (уникальные данные), краткость, clear ask.

### 9.2 Типичные ошибки

**Ошибка:** Generic mass email

```
Hi,
We have great content on our website. Please link to us.
We can also link back to you.
```

**Почему неправильно:** Нет персонализации, нет ценности, link exchange = violation.

**Как исправить:** Изучи сайт, найди конкретную статью, объясни конкретную ценность.
