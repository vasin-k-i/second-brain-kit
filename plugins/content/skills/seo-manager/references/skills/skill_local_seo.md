# Local SEO

**Контекст:** Применяется для оптимизации локального бизнеса под локальный поиск. Результат — стратегия Local SEO с оптимизацией GBP, citation building, review strategy и local content plan.

**Роль:** При использовании этого навыка обязательно ориентируйся на философию и принципы работы роли [@roles/seo_manager/_role_seo_manager.md](../_role_seo_manager.md). Навык определяет КАК выполнять задачу, а роль определяет КАК ДУМАТЬ при её выполнении. Для работы с терминами используй материалы из [`knowledge/`](../knowledge/).

---

## 1. Назначение

### 1.1 Задача навыка

Разработать Local SEO стратегию, которая:
- Оптимизирует Google Business Profile для Local Pack
- Обеспечивает NAP consistency через citations
- Создаёт систему получения и управления reviews
- Разрабатывает local content strategy
- Строит local link building

### 1.2 Data Contract

| | Описание |
|---|----------|
| **Input** | Информация о бизнесе (NAP, категории, услуги), локации, текущий GBP status, конкуренты |
| **Output** | GBP optimization checklist, citation list, review strategy, local content plan, local link opportunities |

---

## 2. Методология

### 2.1 Теоретическая база

**Local Pack Ranking Factors** — три главных фактора: Proximity (расстояние до пользователя), Relevance (соответствие запросу), Prominence (известность бизнеса). Оптимизируем то, что можем контролировать.

### 2.2 Ключевые принципы

- **GBP — фундамент:** Google Business Profile — центральный элемент Local SEO.
- **NAP consistency критична:** Name, Address, Phone должны быть идентичны везде.
- **Reviews = доверие + rankings:** Отзывы влияют на Local Pack и конверсию.
- **Local relevance:** Контент и ссылки от местных источников весят больше.

## 3. Алгоритм выполнения

### 3.1 Шаг 1. Local SEO Audit

**Цель:** Оценить текущее состояние Local SEO.

**Действия:**
1. Google Business Profile status:
   - Claimed и verified?
   - Полнота информации
   - Reviews (количество, рейтинг)
   - Posts и updates
2. NAP audit:
   - Найди все упоминания NAP в интернете
   - Проверь consistency (сокращения, форматы)
   - Выяви несоответствия
3. Local rankings:
   - Позиции по "[service] + [city]" запросам
   - Позиция в Local Pack
   - Видимость в Google Maps
4. Competitor analysis:
   - Топ-3 конкурента в Local Pack
   - Их reviews (количество, рейтинг)
   - Их citations
   - Их GBP completeness

**Результат:** Local SEO baseline и gaps.

---

### 3.2 Шаг 2. Google Business Profile Optimization

**Цель:** Полностью оптимизировать GBP.

**Действия:**
1. **Обязательные элементы:**
   | Элемент | Рекомендации |
   |---------|-------------|
   | Business Name | Точное название без keyword stuffing |
   | Address | Полный, точный адрес |
   | Phone | Локальный номер (не 800) |
   | Hours | Актуальные часы работы |
   | Categories | Primary + all relevant secondary |
   | Description | 750 символов, keywords естественно |
   | Website URL | Ссылка на сайт |
   | Photos | 10+ качественных фото |

2. **Дополнительные оптимизации:**
   - Products/Services с описаниями и ценами
   - Attributes (amenities, accessibility, payments)
   - Q&A — добавь свои FAQ
   - Messaging — включи для коммуникации

3. **Регулярные активности:**
   - Posts каждую неделю (events, offers, updates)
   - Новые фото регулярно
   - Ответы на Q&A
   - Обновление часов (holidays)

4. **Чего избегать:**
   - ❌ Keywords в названии бизнеса
   - ❌ Fake addresses
   - ❌ Duplicate listings

**Результат:** Fully optimized GBP.

---

### 3.3 Шаг 3. Citation Building

**Цель:** Построить consistent citations.

**Действия:**
1. **Data aggregators (приоритет):**
   - Factual
   - Localeze
   - Infogroup
   - Acxiom
   → Данные распространяются на сотни сайтов

2. **Major directories:**
   | Категория | Платформы |
   |-----------|-----------|
   | General | Yelp, Yellow Pages, BBB, Facebook |
   | Industry | TripAdvisor, Healthgrades, Avvo, Houzz |
   | Local | Chamber of Commerce, local newspapers |

3. **Citation audit process:**
   - Найди все существующие citations (Moz Local, BrightLocal)
   - Выяви inconsistencies
   - Исправь несоответствия
   - Добавь на missing platforms

4. **NAP format rules:**
   - Выбери один формат и используй везде
   - "Street" или "St." — consistency важнее формата
   - Включай suite/unit numbers одинаково
   - Phone format одинаковый

**Результат:** Citation list и cleanup plan.

---

### 3.4 Шаг 4. Review Strategy

**Цель:** Создать систему получения и управления reviews.

**Действия:**
1. **Review acquisition:**
   - Ask после успешного взаимодействия
   - Создай direct link на review form
   - Email/SMS reminder через 1-2 дня
   - In-store signage с QR code
   - ❌ Не предлагай incentives
   - ❌ Не покупай reviews

2. **Review response:**
   - **Positive:** Благодарность, персонализация
   - **Negative:** Извинение, решение проблемы, приглашение offline
   - **Fake:** Report платформе, вежливый ответ

3. **Review signals:**
   | Сигнал | Влияние |
   |--------|---------|
   | Quantity | Общее количество |
   | Velocity | Скорость новых |
   | Diversity | На разных платформах |
   | Recency | Свежесть |
   | Rating | Средний рейтинг |
   | Keywords | Упоминание услуг |

4. **Platform priority:**
   - Google (primary)
   - Yelp (важен для некоторых индустрий)
   - Industry-specific (TripAdvisor, Healthgrades)
   - Facebook

**Результат:** Review acquisition и management process.

---

### 3.5 Шаг 5. Local Content Strategy

**Цель:** Создать locally-relevant контент.

**Действия:**
1. **Local landing pages:**
   - Отдельная страница для каждой локации
   - Структура:
     ```
     H1: [Service] in [City]
     - Unique intro paragraph
     - Services offered
     - NAP (schema markup)
     - Embedded Google Map
     - Local testimonials
     - Local photos
     - CTA
     ```
   - ⚠️ Unique content для каждой — не дубликаты

2. **Local content ideas:**
   - Local events coverage
   - "Best [X] in [City]" guides
   - Community involvement stories
   - Local case studies
   - Partnerships с local businesses

3. **LocalBusiness Schema:**
   ```json
   {
     "@context": "https://schema.org",
     "@type": "LocalBusiness",
     "name": "Business Name",
     "address": {
       "@type": "PostalAddress",
       "streetAddress": "123 Main St",
       "addressLocality": "City",
       "addressRegion": "State",
       "postalCode": "12345"
     },
     "telephone": "+1-555-123-4567",
     "openingHours": "Mo-Fr 09:00-18:00",
     "geo": {
       "@type": "GeoCoordinates",
       "latitude": "40.7128",
       "longitude": "-74.0060"
     }
   }
   ```

**Результат:** Local content plan.

---

### 3.6 Шаг 6. Local Link Building

**Цель:** Получить ссылки от местных источников.

**Действия:**
1. **Local link sources:**
   | Источник | Тактика |
   |----------|---------|
   | Chamber of Commerce | Членство |
   | Local newspapers | Coverage, sponsorships |
   | Local blogs | Guest posts, features |
   | Sponsorships | Local events, sports teams |
   | Partnerships | Complementary businesses |
   | Universities | Alumni pages, scholarships |
   | Nonprofits | Donations, volunteering |

2. **Community involvement:**
   - Спонсируй местные события
   - Участвуй в благотворительности
   - Local scholarships → .edu links
   - Expert contributions для local media

3. **Local PR:**
   - Newsworthy stories для local media
   - Grand openings, milestones
   - Community initiatives
   - Expert commentary

**Результат:** Local link building plan.

---

### 3.7 Шаг 7. Multi-Location Strategy

**Цель:** Масштабировать для нескольких локаций.

**Действия:**
1. **Если несколько локаций:**
   - Отдельный GBP для каждой
   - Unique local landing page для каждой
   - Location-specific reviews
   - Local citations для каждой

2. **Site structure:**
   ```
   /locations/
   ├── /locations/city-1/
   ├── /locations/city-2/
   └── /locations/city-3/
   ```

3. **Centralized management:**
   - Brand consistency across locations
   - Unified review monitoring
   - Consistent NAP format

**Результат:** Multi-location strategy (если применимо).

**Результат:** Local SEO стратегия готова.
