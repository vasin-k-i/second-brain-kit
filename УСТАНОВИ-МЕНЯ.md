# Установи меня (задание для Claude Code / Codex)

Человек вставил тебе промпт со ссылкой на этот репозиторий и хочет «Второй мозг»:
папку с заметками, которую ты будешь помнить в каждой сессии, и команды-помощники к ней.
Поставь и настрой всё сам. Он не программист.

**Как говорить с человеком:** коротко, простыми словами, по одному вопросу за раз.
Не пересказывай вывод скриптов, не показывай ошибки целиком, не проси его что-то
набирать в терминале — всё, что можно сделать самому, делай сам.

---

## Шаг 1. Уже стоит или ставим впервые?

Стоит, если в `~/.claude/CLAUDE.md` есть строка `<!-- second-brain-kit:begin -->`
или в `~/.codex/AGENTS.md` — `second-brain-kit`.

**Уже стоит → только обновить.** Ничего не ставь заново: повторная установка может
развернуть пустую папку поверх перенесённой в облако.
```
curl -fsSL https://raw.githubusercontent.com/vasin-k-i/second-brain-kit/main/install/update.sh | bash
bash ~/.second-brain-kit/install/doctor.sh --fix
```
(Windows без bash: `irm https://raw.githubusercontent.com/vasin-k-i/second-brain-kit/main/install/update.ps1 | iex`.)
Скажи человеку одной фразой: «Обновил, заметки не трогал». Дальше — сразу Шаг 4.
Если doctor пишет про шаблонные `{{плейсхолдеры}}` — настройку раньше не провели: иди в Шаг 3.

**Не стоит → Шаг 2.**

## Шаг 2. Установка

Скачай установщик во временный файл, просмотри его и запусти через bash:
```
https://raw.githubusercontent.com/vasin-k-i/second-brain-kit/main/install.sh
```
Не открылся — запасные адреса того же файла (по очереди):
```
https://sb-kit.consul456.workers.dev/sb-lx9wf4cApInIY9VF883j/install.sh
https://vasinki.ru/sb-lx9wf4cApInIY9VF883j/install.sh
```
Установщик сам качает кит, ничего не спрашивает с клавиатуры и ставит заметки в
`~/SecondBrain`. Где хранить на самом деле (компьютер или облако), спросишь в Шаге 3.

- **macOS, Linux** — как выше.
- **Windows:** в Claude Code bash есть всегда (Git Bash) — как выше. Нет bash (бывает в Codex) —
  PowerShell: `irm https://raw.githubusercontent.com/vasin-k-i/second-brain-kit/main/install.ps1 | iex`.
- Установщик пишет вне рабочей папки (`~/.claude`, `~/.codex`, `~/SecondBrain`) и ходит в сеть.
  В Codex сразу запрашивай запуск вне песочницы. Песочница всё равно не пустила — попроси
  разрешение и повтори ту же команду. Обходных путей не ищи.
- В выводе есть «Codex найден, но подключить не вышло» — почти всегда это песочница не дала
  писать в `~/.codex`. Попроси разрешение и запусти `bash ~/.second-brain-kit/install/install-codex.sh`.

Последние строки установщика («перезапусти и набери /setup-second-brain») — для ручной
установки. Человеку их не передавай: дальше ведёшь ты.

Проверь, что всё встало: `bash ~/.second-brain-kit/install/doctor.sh --fix`.
Красное, которое doctor не починил, — почини сам или скажи человеку одной фразой, что не так.

## Шаг 3. Настройка — прямо в этой сессии

Команда `/setup-second-brain` в текущей сессии ещё не видна — это нормально, перезапуск не нужен.
Прочитай файл `~/.second-brain-kit/skills/setup-second-brain/SKILL.md` и проведи по нему
настройку сейчас: где хранить заметки, пять коротких вопросов, файлы с ответами.

## Шаг 4. Финал — одно короткое сообщение

Три-четыре строки, без списков возможностей:
- где лежит второй мозг (путь);
- со следующей сессии я помню твой контекст сам — пересказывать не нужно;
- главные команды: `/capture` — записать мысль, `/find` — найти, `/brain-doctor` — если я «забыл»
  (в Codex то же через `$`: `$capture`);
- только для Codex: при первом запуске он спросит, доверять ли новому хуку, — ответить «да».

Хочет больше — расскажешь, когда спросит.
