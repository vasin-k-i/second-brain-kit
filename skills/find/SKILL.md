# /find — поиск, который отвечает
Ищет в хранилище и даёт собранный ответ, а не голый список файлов. Работает как человек, который знает базу: сначала смотрит в оглавление, потом грепом находит нужные заметки, идёт по их связям и пересказывает суть своими словами, прикладывая ссылки на источники. Полностью keyless — только чтение markdown.

## Как работает
1. Сначала читает `_BRAIN/index.md` и `hot.md` — карту и горячее ядро, чтобы понять, где искать.
2. Грепает хранилище по ключевым словам и синонимам запроса (`rg -i` по `_BRAIN/`).
3. Идёт по вики-ссылкам `[[...]]` из найденных заметок — добирает связанный контекст.
4. Отсекает шум, оставляет релевантное; учитывает даты (свежее важнее).
5. Формулирует ответ по сути запроса, а не пересказ файлов.
6. Прикладывает ссылки на конкретные заметки, где это написано.

## Пример
```
> /find что я решал по ценам
```
Ответ:
```
По ценам были решения:
- Продукт Y — ≈N ₽ (ADR-012, accepted) → _BRAIN/Решения/ADR-012_цена-продукта_2026-06-14.md
- Партнёрские лиды — ≈N ₽/заявка + ≈N ₽/оплата → STACK.md
Связано: заметка о юнит-экономике → _BRAIN/Заметки/Общее/экономика_2026-05-19.md
```
