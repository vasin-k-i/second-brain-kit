# /review — обзор и разбор inbox
Проводит регулярный обзор: подводит итоги периода и разбирает всё, что накопилось в inbox от быстрых захватов. Работает как разбор завалов: за один заход проходит по сырым мыслям, задаёт уточнения пачкой (не по одной), раскладывает их по местам и ставит цели на следующий период. Именно сюда стекаются уточнения, отложенные на этапе /capture.

## Как работает
1. Берёт период (неделя по умолчанию или месяц) и собирает итоги через логику /recap.
2. Открывает `_BRAIN/Заметки/inbox.md` и берёт все записи с `#inbox`.
3. Задаёт уточнения батчем — одним списком вопросов по всем неясным захватам сразу.
4. По ответам маршрутизирует каждый захват: в заметку, решение (/decide), задачу или удаляет; снимает метку `#inbox`.
5. Обновляет связи и `index.md`/`hot.md`.
6. Ставит фокус и цели на следующий период; возвращает итог разбора.

## Пример
```
> /review за неделю
```
Ответ:
```
Итоги недели: (см. recap)
Inbox — 3 записи, уточните пачкой:
1. «лендинг под нишу X» — это идея в бэклог или задача на эту неделю?
2. «вопрос по ценам сервиса X» — закрыт находкой или ещё открыт?
3. «позвонить по проекту A» — задача с дедлайном?
После ответов разложу и почищу inbox. Фокус след. недели: подготовка демо по проекту A.
```
