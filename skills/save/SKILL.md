# /save — сохранить ценное из диалога
Просматривает текущий разговор и раскладывает то, что стоит сохранить, по правильным папкам хранилища. Работает как секретарь после встречи: сам решает, что было решением, что задачей, а что просто фактом, и кладёт каждое туда, где оно потом найдётся. Запускается по сигналу «готово/спасибо» или вручную.

## Как работает
1. Перечитывает диалог и выделяет ценное: решения, задачи, факты/находки, открытые вопросы.
2. Маршрутизирует каждое: решение → `_BRAIN/Решения/`, факт/метод → `_BRAIN/Заметки/`, итог сессии → `_BRAIN/Выводы/<ГГГГ-ММ-ДД>.md`, задачи → дневная заметка или карточка проекта.
3. Дописывает (append) в существующие файлы — append дёшев и безопасен, не переписывает чужое.
4. Ставит даты, теги и вики-ссылки на связанные заметки.
5. Обновляет `index.md`/`hot.md`, если появилось что-то важное.
6. Показывает список: что сохранил и куда (со ссылками), чтобы можно было поправить.

## Пример
```
> спасибо, на этом всё
> /save
```
Ответ:
```
Сохранил:
- Решение «цена курса ≈N ₽» → _BRAIN/Решения/ADR-007_цена-курса_2026-06-14.md
- Находка «сервис X ≈N ₽/единицу» → _BRAIN/Заметки/Общее/стоимость_2026-06-14.md
- Итог сессии → _BRAIN/Выводы/2026-06-14.md (append)
- Задача «сделать лендинг» → дневная заметка
```
