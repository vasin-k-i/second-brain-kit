# /capture — мгновенный захват мысли
Записывает мысль в inbox за один шаг, ничего не уточняя в моменте. Захват — это не разбор: цель — поймать идею, пока она не улетела, а не разложить по полкам. Лёгкий авто-тег ставится сам по тексту, всё спорное откладывается на пакетный разбор в /review.

## Как работает
1. Берёт текст после `/capture` как есть — никаких встречных вопросов.
2. Создаёт строку в `_BRAIN/Заметки/inbox.md` (или файл `_BRAIN/Заметки/inbox/<ГГГГ-ММ-ДД>.md`) с датой и временем.
3. Ставит 1–2 авто-тега по ключевым словам (`#идея`, `#задача`, `#вопрос`, проект из текста) — грубо, без проверки.
4. Помечает запись `#inbox` — значит «ещё не разобрано».
5. Не трогает index/hot и не создаёт связей — это работа /review.
6. Возвращает короткое подтверждение: что записал и куда.

## Пример
```
> /capture идея: лендинг под нишу X
```
Дописывает в `_BRAIN/Заметки/inbox.md`:
```
- 2026-06-14 14:30 #inbox #идея лендинг под нишу X
```
Ответ: «Поймал в inbox (#идея). Разберём на /review.»
