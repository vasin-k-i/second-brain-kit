# /research — исследование без ключей

Собирает досье по теме без единого API-ключа: качает бесплатные открытые источники (Wikipedia, HackerNews, arXiv, Reddit, Semantic Scholar, OpenAlex, dev.to, DuckDuckGo). Сначала сканирует твоё хранилище (vault-first), чтобы не переисследовать известное, затем добирает только пробелы. Каждый факт — с источником, датой и уровнем уверенности.

## Как работает
1. **Vault-first:** греп по хранилищу второго мозга (его путь — в `~/.claude/CLAUDE.md`) — папки `_BRAIN` и `Проекты/` — что по теме уже known, фиксирует как базу.
2. Формулирует пробелы — чего в хранилище нет или что устарело.
3. **Keyless-добор** по бесплатным источникам (без ключей): Wikipedia/REST API, Algolia HN, arXiv, Reddit `.json`, Semantic Scholar Graph API, OpenAlex, dev.to API, DuckDuckGo. Цитирует каждый факт.
4. **Verification-first:** каждый факт несёт `(на ГГГГ-ММ, источник)` и уровень уверенности — высокий / средний / низкий. Противоречия между источниками показываются явно, а не сглаживаются.
5. Результат — досье: что знали, что добрали, открытые вопросы. Опционально предлагает дописать находки обратно в `_BRAIN/Заметки`.

Работает без API-ключей. Опционально `/verify` — активная пересверка ключевых фактов по нескольким источникам (предупреждает: это стоит токенов).

## Пример
`/research сколько стоит инференс модели X vs модели Y за 1M токенов`
> Из хранилища (vault-first): в `STACK.md` цены за 1M токенов помечены «внести» — пробел, идём в источники.
> Добор (keyless):
> - В твоём профиле расход на сервис X ≈ N ₽/мес при текущем темпе (на 2026-06, `STACK.md`) — уверенность высокая (твои данные).
> - Тарифные сетки моделей — официальные страницы цен провайдеров через DuckDuckGo/Wikipedia (на 2026-MM, источник) — уверенность средняя, цены часто меняются.
> Открытый вопрос: точные ставки за 1M на сегодня — кандидат под `/verify`.
> Записать в `STACK.md` (раздел «Стоимость моделей»)? y/n
