# /daily — заметка дня
Заводит на сегодня одну заметку-дневник и дополняет её в течение дня. Работает как ежедневник: открыл утром — увидел план, в течение дня дописал сделанное, вечером — готовый срез дня. Если заметка уже есть — не создаёт новую, а добавляет в неё.

## Как работает
1. Проверяет, есть ли `_BRAIN/Выводы/<ГГГГ-ММ-ДД>.md` (или `_BRAIN/Дни/<ГГГГ-ММ-ДД>.md`) на сегодня.
2. Если нет — создаёт со скелетом: «Сделано», «Задачи», «Заметки дня».
3. Если есть — дописывает (append) в нужный раздел, не трогая остальное.
4. Подтягивает незакрытые задачи из вчерашней заметки.
5. Связывает упомянутые проекты вики-ссылками `[[...]]`.
6. Возвращает текущий вид заметки дня.

## Пример
```
> /daily сделал черновик по проекту A, осталось согласовать макет
```
Дописывает в `_BRAIN/Выводы/2026-06-14.md`:
```
## Сделано
- Черновик по проекту A
## Задачи
- [ ] Согласовать макет
- [ ] Подготовить демо
```
Ответ: «Обновил заметку дня (2026-06-14).»
