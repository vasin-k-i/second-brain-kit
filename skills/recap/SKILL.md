# /recap — сводка за период
Собирает короткий отчёт за выбранный период из дневных заметок, выводов и решений. Работает как итог планёрки: пробегает по всем записям диапазона и выдаёт связную картину — что сделано, какие решения приняты, что повисло — вместо того чтобы листать каждую заметку вручную.

## Как работает
1. Определяет период из запроса: день / неделя / месяц (по умолчанию — неделя).
2. Собирает файлы диапазона из `_BRAIN/Выводы/`, дневных заметок и `_BRAIN/Решения/`.
3. Группирует: сделано, принятые решения (ADR), находки, незакрытые задачи.
4. Сворачивает повторы и мелочь, оставляет значимое.
5. Даёт связную сводку со ссылками на источники.
6. В конце — короткий вывод и что перенести вперёд.

## Пример
```
> /recap за неделю
```
Ответ:
```
Неделя 2026-06-08 — 2026-06-14:
Сделано: черновик и план v3 по проекту A; запущен первый этап.
Решения: ADR-012 цена продукта Y — ≈N ₽ (accepted).
Находки: дешёвый сервис X для рассылок (<0.2 ₽/письмо).
Осталось: финальная вычитка, подготовка демо.
Вывод: основной результат почти готов — закрыть вычитку и собрать демо.
```
