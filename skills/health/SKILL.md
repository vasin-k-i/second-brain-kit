# /health — здоровье хранилища
Проверяет хранилище целиком и показывает, где оно «болеет»: противоречащие друг другу факты, незаполненные дыры, заметки без единой связи и устаревшие данные. Работает как ревизор склада: ничего не выбрасывает сам, а составляет список проблем и предлагает, что починить. Запускать периодически.

## Как работает
1. Сканирует `_BRAIN/` и строит карту заметок и вики-ссылок `[[...]]`.
2. Ищет противоречия: один факт с разными значениями (например, две разные цены одного товара).
3. Находит дыры: ссылки `[[...]]` на несуществующие заметки, пустые карточки, нераскрытые TODO.
4. Находит сирот: заметки, на которые никто не ссылается и которых нет в index.
5. Помечает устаревшее: старые даты «Обновлено», факты с истёкшим сроком (токены, цены).
6. Выдаёт отчёт с приоритетами и конкретными предложениями по чистке — без автоправок.

## Пример
```
> /health
```
Ответ:
```
Здоровье хранилища:
ПРОТИВОРЕЧИЯ (1): цена курса ≈N ₽ в ADR-007 vs ≈M ₽ в карточке проекта.
ДЫРЫ (2): [[юнит-экономика]] нет файла; карточка проекта A без домена.
СИРОТЫ (3): Заметки/Общее/старая-идея_2026-03.md — нет ссылок и не в index.
УСТАРЕЛО (1): токен сервиса X помечен живым, но протух (auth-ошибка).
Предлагаю: свести цену, создать [[юнит-экономика]], добавить сирот в index.
```
