# Второй мозг на Claude Code

> Цифровой сотрудник, которым один человек ведёт несколько проектов. Не курс про «думать лучше», а **рабочий каркас**, который ставится в один шаг и сам себя настраивает руками агента.

**Claude Code делает работу — Obsidian хранит память.** Ставишь одной командой → Claude задаёт несколько вопросов → у тебя персональный второй мозг: контекст не теряется между сессиями, заметки ведутся сами, проекты под рукой.

## Что внутри
- **Каркас `_BRAIN/`** — структура памяти (фокус, проекты, инфраструктура, заметки, решения, выводы).
- **Мост памяти** — горячее ядро автоподгружается в каждую сессию (токен-эффективно).
- **Метод автора** — поведенческие правила: критическая оценка до выполнения, не оверинженерить, записывать находки обратно.
- **Скиллы (ставишь только нужные):**
  - захват и поиск: `/capture`, `/save`, `/find`, `/ingest`, `/health`
  - мышление: `/challenge`, `/emerge`, `/panel`, `/connect`
  - ритм: `/daily`, `/recap`, `/review`, `/decide`
  - исследование без ключей: `/research`
  - контент: сценарии / Продюсер / SEO-manager
- **Модули (опционально):** видео-пайплайн (нужна подписка Higgsfield), SEO + правила работы с сайтами.

> ℹ️ В публичной версии **нет текстового суперскилла Writer** (копирайтинг по школе Ильяхова) и конспектов чужих книг/курсов — это материалы по платному IP, в открытый репозиторий они не выкладываются. Полная версия с Writer доступна через [бота канала](https://t.me/vasin_launch_bot).

## Установка (одна команда)
**Способ 1 — терминал (macOS / Linux; Windows — через Git Bash).** Вставь и нажми Enter:
```
curl -fsSL https://raw.githubusercontent.com/vasin-k-i/second-brain-kit/main/install.sh | bash
```
Скачает кит в `~/.second-brain-kit`, развернёт каркас `_BRAIN/`, мост памяти и скиллы.
⚠️ Запускай в системном терминале, **не внутри Claude Code**.

**Способ 2 — через Claude Code (`/plugin`):**
```
/plugin marketplace add https://github.com/vasin-k-i/second-brain-kit
/setup-second-brain
```

Дальше открой Claude Code и запусти `/setup-second-brain` — Claude проведёт интервью и наполнит второй мозг под тебя.

> **macOS / Linux:** работает из коробки (bash, `~/.claude`).
> **Windows:** то же, но пути через `%USERPROFILE%`, хук на PowerShell — отличия помечены в инструкции по пунктам.

## Требования
- Claude Code (установлен и залогинен) — если нет, бутстрап даст команду установки.
- Obsidian — опционально (каркас это markdown, открывается как vault когда удобно).

## Лицензия / приватность
Каркас и метод — обобщённые, без личных данных автора. Твоё личное наполняет интервью; секреты в `.md` не пишем — только указатели.
