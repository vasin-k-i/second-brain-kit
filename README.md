# Второй мозг на Claude Code

> Цифровой сотрудник, которым один человек ведёт несколько проектов. Не курс про «думать лучше», а **рабочий каркас**, который ставится в один шаг и сам себя настраивает руками агента.

**Claude Code делает работу — Obsidian хранит память.** Вставляешь один промпт → агент сам ставит и задаёт несколько вопросов → у тебя персональный второй мозг: контекст не теряется между сессиями, заметки ведутся сами, проекты под рукой.

## Что внутри
- **Каркас `_BRAIN/`** — структура памяти (фокус, проекты, инфраструктура, заметки, решения, выводы).
- **Мост памяти** — горячее ядро автоподгружается в каждую сессию (токен-эффективно).
- **Метод автора** — поведенческие правила: критическая оценка до выполнения, не оверинженерить, записывать находки обратно.
- **Скиллы (ставишь только нужные):**
  - захват и поиск: `/capture`, `/save`, `/find`, `/ingest`, `/health`
  - мышление: `/challenge`, `/emerge`, `/panel`, `/connect`
  - ритм: `/daily`, `/recap`, `/review`, `/decide`
  - исследование без ключей: `/research`
  - контент: сценарии / Продюсер / SEO-менеджер
- **Модули (опционально):** видео-пайплайн (нужна подписка Higgsfield), SEO + правила работы с сайтами.

## Установка — один промпт
Открой **Claude Code** или **Codex** и вставь:
```
Установи мне «Второй мозг»: https://github.com/vasin-k-i/second-brain-kit
Сделай всё по файлу УСТАНОВИ-МЕНЯ.md оттуда.
```
Дальше агент всё поставит сам и задаст несколько вопросов. Уже стоит — он только обновит.

> **Агенту:** задание — в [УСТАНОВИ-МЕНЯ.md](УСТАНОВИ-МЕНЯ.md). Читай его и делай по нему.

Руками, в терминале (macOS / Linux / Git Bash):
```
curl -fsSL https://raw.githubusercontent.com/vasin-k-i/second-brain-kit/main/install.sh | bash
```
Потом в Claude Code: `/setup-second-brain`. Обновить: `…/main/install/update.sh | bash`.

## Если что-то не работает
Мозг «не помнит»? Не гадай — проверь цепочку одной командой:
```
/brain-doctor
```
или в терминале: `bash ~/.second-brain-kit/install/doctor.sh --fix`

Смотрит, где лежат заметки, подключён ли мост памяти, запускается ли движок автозагрузки,
все ли команды на месте, не раздулось ли ядро — и чинит найденное. Частый случай, который он
закрывает сам: мозг перенесли в облако, а настройки остались на старой папке.

## Codex — тот же мозг
Если на компьютере есть Codex, установщик подключает его автоматически: те же команды
(вызываются через `$`, например `$capture`), тот же мост памяти (`~/.codex/AGENTS.md`) и тот же
движок автозагрузки ядра. Заметки общие — правь откуда удобно.

Вручную: `bash ~/.second-brain-kit/install/install-codex.sh`
Не нужен — `SB_NO_CODEX=1` перед установкой.

> При первом запуске Codex спросит, доверяешь ли новому хуку. Ответь да — иначе контекст
> не будет подгружаться сам.

## Требования
- Claude Code (установлен и залогинен) — если нет, бутстрап даст команду установки.
- Obsidian — опционально (каркас это markdown, открывается как vault когда удобно).
- Codex — опционально, поддерживается наравне с Claude Code.

## Лицензия / приватность
Каркас и метод — обобщённые, без личных данных автора. Твоё личное наполняет интервью; секреты в `.md` не пишем — только указатели.
